# Dojoventura

- **Diretório do Cliente:** `dojoventura`
- **Data de Criação:** 2026-09-09
- **Stack:** Astro + Tailwind CSS + Cloudflare Pages & Turnstile
- **Padrão de Qualidade:** Arquiteto Web Elite V5.0

## Estrutura da Pasta
- `website/`: Código-fonte da aplicação Astro.
- `docs/`: Briefing, escopo contratual e ficha de acessos (`accesses.md`).
- `assets/`: Logotipos, fotos em alta resolução, vídeos e materiais brutos.
- `.cursorrules`, `CLAUDE.md`, `AGENTS.md`: Instruções universais para LLMs (Cursor, Claude, Codex, etc.).

## Comandos Rápidos
```bash
cd website
npm install
npm run dev
npm run build
```
